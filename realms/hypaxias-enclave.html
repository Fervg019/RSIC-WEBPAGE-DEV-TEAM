Realms/06 Computer Science

Hypaxia's Enclave

It compiles or it doesn't.

Hypaxia's Enclave is a build-and-defend round. Write it, break it, then explain exactly why it broke. Algorithms, systems thinking and the occasional deliberately broken codebase.

06
Theme

Algorithmic problem solving

Format

Team coding + live defence

Team size

2 to 3

Duration

4 hours

Rules

  1. One shared judge-provided machine per team. No personal laptops during the round.
  2. Internet access is restricted to a whitelisted documentation set.
  3. Code must be committed at fixed checkpoints, not just at the end.
  4. Plagiarism detection runs on all submissions.
  5. Defence is mandatory. Undefended solutions are not scored.

Judging criteria

  • Correctness35%
  • Efficiency25%
  • Code quality20%
  • Defence20%

Requirements

  • Delegate ID
  • Team registered under one account
  • Own peripherals (mouse/headphones) permitted
  • No personal storage devices

Schedule & materials

  • Full timings are released with the event schedule on the Updates page.
  • Room and stage assignments are confirmed the week of RSIC.

Heads upAny attempt to access non-whitelisted resources ends the round for that team immediately.
